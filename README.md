# PM Case Practice

A static site for practising product management interviews with a friend. One person plays the interviewer, the other the candidate.

- **Full cases with data:** a case brief and data exhibits that both people see, plus an answer guide (follow-ups, strong-answer checklist, key insight, rubric) for the interviewer.
- **Question bank:** hundreds of commonly reported PM interview questions, filterable by category, company and difficulty.

No build step. Open `index.html`, or serve the folder with any static server:

```bash
npx serve .
```

Content lives in `pm/`: `cases-*.js` (full cases) and `bank.js` (question bank and sources).
